---

## 2. Descripción y Función en el Sistema

Las secadoras industriales Renzacci de las series **R PLUS y RZ PLUS** están diseñadas para uso intensivo en lavanderías autoservicio y entornos profesionales.

Estas máquinas permiten el secado rápido de ropa mediante circulación de aire caliente en un tambor rotativo. Incorporan control electrónico de programas y sistemas de seguridad para evitar sobrecalentamiento.

Dentro del sistema **LAVANDERÍA KWL**, las secadoras forman parte del servicio principal ofrecido a los clientes.

Su activación se realiza mediante el sistema de pago compuesto por:

- monedero **Comestero RM5 Evolution**
- interfaz **Comestero MPS1**

Cuando el sistema de pago valida el crédito, la interfaz habilita el inicio del ciclo de secado.

## 4. Implementación en LAVANDERÍA KWL

En el sistema se utilizan:

- **2 secadoras Renzacci**

Cada secadora está conectada a:

- un monedero **Comestero RM5 Evolution**
- una interfaz **Comestero MPS1**

Flujo de funcionamiento:

1. El cliente introduce monedas.
2. El monedero valida el crédito.
3. La interfaz MPS1 comunica el crédito a la máquina.
4. La secadora habilita el inicio del programa de secado.

El sistema IoT no controla directamente los ciclos internos de secado.

---

## 6. Riesgos y Consideraciones Técnicas

Posibles fallos:

- fallo del sistema de pago
- fallo de resistencia o sistema de calefacción
- acumulación de pelusas en filtros
- fallo del ventilador de aire

Impacto en el sistema:

- la máquina queda fuera de servicio
- reducción de capacidad de servicio en la lavandería

Consideraciones técnicas:

- requiere mantenimiento periódico del sistema de filtrado
- limpieza regular de conductos de aire
- funcionamiento independiente del sistema IoT
